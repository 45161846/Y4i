# 👩‍🏫 Y4i

Многопользовательское приложение для наработки тестовых и типовых заданий. Добавляй свои карточки или тренируйся на специальных подборках

- Удобный интерфейс
- Своя пополняемая база заданий
- Трекинг статистики

На данный момент необходимо поднимать свой [сервер](https://github.com/45161846/y4i-server) в локальной сети или  воспользоваться [оффлайн]() версией с выдуманными данными

---
# 🛠 Стек

- **UI** 
  - Полностью на Compose: все экраны, компоненты и навигация
  - Кастомные модификаторы и анимации
  - Material 3 дизайн-система с динамической темной/светлой темой и возможностью переключения
  - State management через ViewModel + MVI архитектура
- **Kotlin Coroutines + Flow** - асинхронные операции
- **Hilt** - dependency injection
- **Room** - хранение данных, `1-1`, `1-N`, `N-N` отношения
- **Ktor** - походы в сеть
- **Shared Preferences** - настройки работы приложения

# 🌐 Back-end
Свой небольшой [сервер](https://github.com/45161846/y4i-server) с базой данных на `Exposed`. Всё общение через JSON сериализацию

# Плюшки
- Первый в своём роде игровой интерфейс специально подстроенный для фокусировки внимания на необходимой информации:
  - Взаимодействие только с выбором необходимой части
  - Без выписывания номеров правильных ответов
  - Без печатания на клавиатуре, когда надо выбрать всего из двух букв и тп
- Кастомные UI-элементы
  - ✒️ `Читать далее...` Текст с настраиваемым постфиксом при переполнении контейнера. Бинпоиском ищет подходящую подходящую длину, чтобы ровно заполнить контейнер. Из коробки предоставляется только `...` на конец
  - 🍏 IOS-подобные свичи в настройках
  - ⭐ Рейтинг соответственно заполненный частичными звёздочками
